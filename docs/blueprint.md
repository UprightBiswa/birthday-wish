# **App Name**: Birthday Wishes Creator

## Core Features:

- Customizable Birthday Message: Allow users to input a name, age, and personalized message to create a custom birthday wish.
- Image Upload and Integration: Enable users to upload an image (local asset) to be included in the birthday wish presentation.
- Confetti Animation: Incorporate a celebratory confetti animation on the birthday wish screen to enhance the festive atmosphere.
- Background Sound: Add background music with Happy Birthday song for birthday wishes

## Style Guidelines:

- Primary color: Festive purple (#A06CD5) to evoke a celebratory and joyful mood.
- Background color: Light lavender (#E6E0ED), a very desaturated tint of the primary.
- Accent color: Bright magenta (#D56CA0) to create contrast with a bit of added visual playfulness.
- Body and headline font: 'Poppins', sans-serif, to maintain a clear and joyful design. Note: currently only Google Fonts are supported.
- Use simple, joyful icons (e.g., cake, balloons) to enhance the celebratory theme.
- The layout will feature a vertically centered design, ensuring balance. The background image will take up the majority of the screen, while the birthday message and name are clearly displayed, achieving harmony and visual impact.
- Smooth, subtle animations for text and image transitions to enhance the user experience.
